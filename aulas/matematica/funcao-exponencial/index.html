1. A Função Exponencial

O que é uma Função Exponencial?

Enquanto uma função de 1º grau (linear) cresce através de somas constantes, a função exponencial descreve fenômenos que crescem através de multiplicações constantes. Ela é o modelo matemático por trás da reprodução de bactérias, juros compostos e decaimento radioativo.

f(x) = ax

Onde a é a base (um número real) e x é o expoente (a variável). Para que essa função exista nos números reais e não se torne uma simples reta, a base possui duas regras invioláveis:

  • a > 0 (A base deve ser estritamente positiva, evitando raízes de números negativos).
  • a ≠ 1 (Se a = 1, o resultado seria sempre 1, tornando-se uma função constante).

Comportamento Gráfico

O gráfico exponencial nunca toca o eixo X (o zero absoluto). Dependendo da base escolhida, a curva se comporta de duas maneiras:

Crescente (a > 1):
Quanto maior o X, maior o Y de forma acelerada. A curva dispara para o alto no lado direito.
Decrescente (0 < a < 1):
Quanto maior o X, mais o Y se aproxima de zero (sem nunca encostar).

Ponto Fundamental: Qualquer que seja a base válida, a curva sempre cruzará o eixo Y no ponto (0, 1). Isso ocorre porque qualquer número não nulo elevado a zero é igual a 1 (a0 = 1).
